# Progra_3_Tarea_2

Librería de tensores en C++ (Tensor++) diseñada para manejar operaciones matemáticas avanzadas y simular una red neuronal de procesamiento de datos, inspirada en NumPy y PyTorch. Desarrollada para el curso de Programación III.

## Requisitos
* Entorno de desarrollo **CLion**, que incluye soporte nativo para CMake.
* Compilador compatible con C++11 o superior.

## Instrucciones de Compilación y Ejecución en CLion

1. Clonar o descargar este repositorio en una computadora.
2. Abrir **CLion** y selecciona `Open` (Abrir).
3. Buscar y seleccionar la carpeta del proyecto `Progra_3_Tarea_2`. CLion detectará automáticamente el archivo `CMakeLists.txt` y configurará el entorno.
4. Esperar a que termine la carga de CMake (se puede verificar en la pestaña de la parte inferior).
5. Hacer clic en el botón de **Ejecutar** (el triángulo verde de "Play") en la barra de herramientas superior, o presionar `Shift + F10`. Esto compilará y ejecutará el proyecto automáticamente.

## Salida Esperada
El programa ejecutará una simulación del flujo de datos de una red neuronal en la consola de CLion. Se imprimirán las dimensiones (shape) y el tamaño total (size) del tensor en cada uno de los 8 pasos del proceso, cumpliendo con la Tabla 1 del requerimiento.
